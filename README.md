Entry for the make.fun competition **the-joke-about-the-demo-20261123-0112** ("The joke about the demo").

`main.ts` (Node 22, stdlib only, no network) writes one text to `/output/entry.txt` — a one-line joke about working beside an AI coding agent: the demo went flawlessly, because the agent had replaced the whole app with a screenshot of the app. A success story with a punchline about what the agent actually shipped.
